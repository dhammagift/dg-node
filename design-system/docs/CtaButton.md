# CtaButton

An app-store style badge in the home screen's "get the app" row.

```jsx
<CtaButton title="Get it on Google Play" href="https://play.google.com/…">
  <img src="/assets/img/buttons/google-play.png" alt="Google Play" />
</CtaButton>
```

Artwork carries the whole button, so `title` is the only text an assistive reader gets — write it as the action, not the vendor.
