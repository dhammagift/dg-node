# Tile

One home-screen shortcut: a glyph in an accent disc with a caption under it.

```jsx
<Tile label="Dīgha Nikāya" icon={<Icon name="book" size={20} />} description="34 long discourses" />
```

Always a button, never a link — browsers start their own drag on anchors, which would fight tile reordering. Tiles are user-reorderable and hideable in the app.
