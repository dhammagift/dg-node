# PaliQuote

A canonical quotation set as a block: Pali line, translation, references, and an optional caveat.

```jsx
<PaliQuote
  pali="Sabbe saṅkhārā aniccā"
  translation="All conditioned things are impermanent."
  refs={<a href="/dhp277">Dhp 277</a>}
/>
```

The Pali line is marked `lang="pi"`, which is what gives it the serif face and the dictionary lookup.
