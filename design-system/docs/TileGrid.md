# TileGrid

The home screen's grid of shortcuts.

```jsx
<TileGrid>
  <Tile label="Suttas" icon={<Icon name="book" size={20} />} />
  <Tile label="Vinaya" icon={<Icon name="dharmachakra" size={20} />} />
</TileGrid>
```

Lay tiles out here rather than in a bespoke grid — the spacing and wrap behaviour are part of the home screen's identity.
