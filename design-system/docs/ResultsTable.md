# ResultsTable

The search results table — an index of suttas first, a list of hits second.

```jsx
<ResultsTable>
  <ResultRow suttaId="dn22" paliTitle="Mahāsatipaṭṭhānasutta" translatedTitle="Большое наставление о способах установления памятования" />
</ResultsTable>
```

Rows expand in place to reveal the matching segments, so keep the row itself to identity and provenance.
