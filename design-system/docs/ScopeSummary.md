# ScopeSummary

Spells out which books a search actually covered, grouped the way the canon is.

```jsx
<ScopeSummary groups={[
  { title: '4 Nikāyas', books: ['Dīgha', 'Majjhima', 'Saṁyutta', 'Aṅguttara'] },
  { title: 'Khuddaka', books: ['Dhammapada', 'Udāna', 'Itivuttaka'] },
]} />
```

The results header shows a short label ("4 Nikāyas + 6 KN"); this is the expansion behind it, so a reader can tell what was not searched.
