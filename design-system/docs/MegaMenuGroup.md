# MegaMenuGroup

One titled cluster inside a MegaMenu.

```jsx
<MegaMenuGroup title="Translators" layout="chips">
  <SheetRow label="Sujato" chip />
  <SheetRow label="Thanissaro" chip />
</MegaMenuGroup>
```

Sets whose labels speak for themselves — model names, edition codes — use the chip layout: four names like "Gemini" do not earn four full-width rows.
