# Чек-лист теста APK (Android, Capacitor)

Проверять **сверху вниз** — сначала то, что ломает приложение целиком, потом мелочи.
Сборка: https://test.dhamma.gift/mobile-apk/ (`dg-app-latest.apk` — всегда последняя).
Если что-то падает — лучше сразу `adb logcat | grep -iE "dg-offline|chromium|sqlite"` или
`chrome://inspect` по USB: без лога причина гадается.

## 1. Блокеры (без них приложение бессмысленно)

| # | Что | Как проверить | Ожидание |

| 1.1 | Первый запуск и загрузка базы | поставить APK, открыть, согласиться на загрузку | прогресс-карточка с **процентами и «X из 509 МБ»** (не «бегающая» полоса), «Library ready» |

| 1.3 | Обрыв/возврат к загрузке | убить приложение в середине, открыть снова | загрузка продолжается с места обрыва (докачка), а не с нуля |
| 1.4 | Офлайн-поиск | авиарежим → вкладка поиска → `kacchapa` | результаты из локальной базы |

## 5. Известные ограничения (не баги, проверять не нужно)

- Языки офлайн-базы — только ru + en; другие требуют интернета (честное сообщение).
- Озвучка Google и конвертация письма (`?script=`) офлайн не работают — уходят на сервер.
- Два случая паритета поиска (`search-russian`, `search-punctuation`) расходятся с сервером —
  открытое решение по языкам среза (`TODO.md`), см. `docs/OFFLINE_PWA_PLAN.md`.
- `/docs/*`, `/memo/`, `/login` в приложение не входят — открываются в браузере (по решению).
- FTS/шрифты: subset-шрифты Lato/Brahmi отсутствуют и на сайте (404 там же).

## Как сообщать о проблеме

Что нажимал → что ожидал → что увидел (скриншот) + `adb logcat` при падении. Для загрузки —
версия сборки (Настройки → App version) и состояние «Офлайн-библиотека».

## Если что-то пошло не так с диском

Тесты с офлайн-базой создают браузерный профиль (~500–900 МБ) и **удаляют его по завершении**.
Если прогон прервали — профиль останется. Сторож чистит его сам:

```bash
node scripts/disk-guard.js      # один проход: ниже 6 ГБ — чистит свои временные артефакты, ниже 2 ГБ — ALERT
tail -20 test/.disk-guard.log   # журнал сторожа (cron: каждые 10 минут)
```

Скачивание базы в проверках разрешено только с `DG_APP_UI_ALLOW_DOWNLOAD=1` и при ≥3 ГБ свободного
места; `DG_APP_UI_KEEP_PROFILE=1` оставляет профиль для отладки (не забыть удалить).

## Осталось (не проверено на устройстве)

- уведомление с процентами и загрузка при **выключенном экране** (wake lock в сервисе) — v1.10+;
- шорткаты в лончере: Contents и Favorites (закреплённые, ранги 0/1) + «недавние» (ранги 10+);
- шаринг внутрь (текст из другого приложения) и наружу;
- сплеш и статус-бар при тёмной теме.
