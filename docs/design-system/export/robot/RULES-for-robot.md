# Правила для ИИ-помощника в этом проекте

## Главное правило: ничего не удалять «за ненадобностью»

Прототипы в `guidelines/redesign/` — это макеты **существующего прода** dhamma.gift.
Каждый элемент интерфейса там повторяет реальную функцию сайта. Если функция кажется
лишней, редкой, «служебной» или непонятной — **это не повод её убирать**. Убирать
что-либо можно ТОЛЬКО по прямой просьбе владельца проекта.

При правках: менять оформление, композицию, типографику — да. Вырезать функции — нет.
Если для новой композиции чего-то не хватает места — свернуть, спрятать в панель или
спросить, но не удалять.

## Обязательный инвентарь прода (должен быть в макетах)

Поиск и шелл
- Пилюля поиска: ракушка (ссылка на главную), поле, «×» очистки, кнопка-ползунки
  (быстрые настройки), лупа.
- Быстрые настройки (`#qsp`): область поиска (4 Никаи, 6 КН, Виная), регистр,
  диакритика, вид выдачи, набор диакритики.
- Строка «область поиска · изменить» на главной; на мобильном — ползунки в поле.

Выдача
- Два вида выдачи: по текстам (`#dt-texts`) и **отчёт по словам** (`#dt-words`).
- Строка управления таблицей: «на странице», пагинация (сверху и снизу),
  поле «Фильтр» и кнопка-ползунки рядом с ним.
- **Продвинутый фильтр** (`#advf`) — билдер условий (поле / оператор / значение,
  «Добавить условие», «Очистить всё»). Открывается кнопкой-ползунками у поля
  «Фильтр». Это прод-функция, не декорация.
- Раскрытие строки (►) с контекстом совпадений; колонки Ct/Mr; ссылки Pi/En/Ru;
  отметка прочитанного.
- Полная строка ссылок под таблицей (`.dtlinks`): Главная, История, Экспорт, Читать,
  Make List, List Diff, Sutta Diff, Видимость — **одинаковая для обоих видов выдачи**.

Ридер
- Липкая шапка сутты, оглавление раздела (`#sectoc`), режимы чтения (в бургере),
  варианты чтения, озвучка (`.playpill`), языковая пилюля + меню языков,
  избранное (звезда), поиск по странице (`.findbar`).

Оглавление
- Дхамма / Виная, вложенность вагга → сутты, фильтр переводчиков (`.trfilter`).

Общее
- Бургер-меню (`#drawer`), мультитул «Избранное / История / Окно 4БИ» (`#multi`),
  панель «Как искать» (`#sheet`), подборки (карусель), цитата dn16/an4.180,
  предупреждение о переводах, подвал (ссылки, легал, соцсети), плашка Beta.
- Переключение темы (светлая/тёмная), переключение десктоп/мобильный вид.
- Страница **404**: крупная цифра, «Aho! Страница не найдена. Но…», цитата sn38.4,
  кнопка «На главную», сетка разделов 4×2.

## Технические договорённости

- Токены и цвета — только из `styles.css` / `tokens/` (`--dg-*`). Своих hex не вводить.
- Иконки: свой набор `assets/svg` через CSS-маску (`.gi` + `--u:url(...)`).
  FontAwesome — только там, где своего глифа нет.
- Комментарии в коде на русском, объясняют «почему», а не «что».
- Крупные правки — новой версией файла, старую не переписывать без просьбы.
- Файлы в `guidelines/redesign/`: `A/B/C` — черновые направления, `D-refresh` —
  основной макет (5 экранов, переключатель внизу справа), `E-404` — отдельный 404,
  `*-standalone` — самодостаточные сборки (могут отставать от исходников).

## Что в этой папке

- `guidelines/redesign/G-reader.html` — макет ридера (экран чтения) на разработку.
  Внутри весь прод-инвентарь чтения: липкая шапка сутты, оглавление раздела (#sectoc),
  режимы чтения (в бургере), варианты чтения, озвучка, кнопка «Наверх», языковая пилюля
  и меню языков, избранное, поиск по странице (.findbar), подвал ридера, быстрые
  настройки (#qsp), бургер (#drawer), мультитул (#mt). Переключатель «Мобильный» — внизу справа.
- `styles.css` + `tokens/` — токены и темы (`--dg-*`), светлая и тёмная.
- `assets/svg`, `assets/img`, `assets/fonts` — иконки (CSS-маска), логотипы, шрифт.

Пути в макете относительные (`../../styles.css`, `../../assets/...`), структура папок
сохранена — открывать файл прямо из этой папки. FontAwesome подключается с CDN.
