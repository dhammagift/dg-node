Ключевые особенности

Dhamma.gift — это набор связанных инструментов вокруг Палийского канона (Сутта и Виная) и его переводов: поиск, построчный ридер, словарь пали и плеер синтеза речи, объединённые так, чтобы найти отрывок, прочитать его с переводом, прослушать и заучить можно было в одном непрерывном сценарии, а не в разных приложениях.

Dhamma.Gift — мультитул / портал в одно окно​

Dhamma.gift был создан с целью собрать в одном месте лучшие онлайн-ресурсы по Дхамме и Пали, включая тексты, словари, важные сайты, электронные книги и инструменты. Все они доступны в «Коллекции ссылок» в панели инструментов под полем поиска — см. MultiTool. Если вам кажется, что чего-то не хватает, сообщите нам!

Find.Dhamma.Gift — поиск по Суттам и Винае​

Инструмент для тех, кто хочет систематизировать информацию по палийским Суттам и Винае. Результаты представлены в удобных таблицах с базовой и продвинутой фильтрацией, разными сортировками и группировкой по текстам и по словам. Даёт прямой доступ к пали-текстам с построчным переводом на русский и английский и внешними ссылками на Theravada.ru, Theravada.su, DigitalPaliReader.online, TheBuddhasWords.net, SuttaCentral.net. См. Поиск.

Dhamma.Gift Read — построчное чтение со всплывающим словарём​

  • Единственный ресурс с таким объёмом построчно расположенных пали-русских текстов: АН, ДН, МН, СН, КН (Snp, Уд, Iti, Дхп, Тхаг, Тхиг), а также частично Виная-Вибханга.
  • Единственный сайт со встроенной онлайн русской версией Digital Pāḷi Dictionary (DPD) — всплывающий по клику словарь.
  • Многоязычный режим — одновременное отображение пали, русского и английского переводов.
  • Избранное и История — личная библиотека текстов для быстрого доступа.
  • Прогресс чтения — продолжайте с того места, где остановились.
  • Облачная синхронизация — избранное, история, прогресс чтения и настройки (языки, тема, шрифт) синхронизируются между устройствами анонимно, по секретной кодовой фразе — без email и регистрации.
  • Полноценный онлайн-словарь DPD, а также интеграция с DictTango (Android), Mdict (iOS), GoldenDict-NG (десктоп) и Dharmamitra.org для глубокого грамматического разбора.
  • Умный TOC — быстрая навигация, адаптирующаяся под выбранные языки. См. Навигатор TOC.
  • Режимы чтения — без пунктуации, режим заучивания, помощник для нелатинских систем письма (деванагари, тайская и др.) и другие режимы. См. Ридер.
  • Интеграция с голосом — переход от чтения к прослушиванию или заучиванию любой фразы одним кликом. См. Голос / TTS.
  • Горячие клавиши для быстрой навигации.

Dhamma.Gift Voice — единая экосистема текста и звука​

Комплекс инструментов для озвучивания канонических текстов, встроенный прямо в процесс чтения, а не отдельное приложение для фонового прослушивания.

1. Плеер режима чтения — интегрирован прямо в интерфейс сутт:

  • чередование пали и перевода в любом порядке;
  • паузы между фразами — настраиваемая задержка для осмысления или повторения вслух;
  • A-B Loop — зацикливание любого фрагмента для внимательного прослушивания;
  • встроенные голоса устройства (например, санскритский модуль на Android хорошо читает пали) — работает офлайн;
  • голоса от Google — большой выбор, качественнее встроенных;
  • автопрокрутка и подсветка активного фрагмента.

2. Памятование и медитация («Мемо») — заучивание текстов наизусть или создание аудио-медитаций:

  • супер-гибкий TTS — индивидуальная настройка озвучки для любого текста;
  • тонкая нарезка текста на смысловые блоки по точкам, запятым или строкам;
  • настраиваемое число повторов и пауз для каждой фразы;
  • гонг в конце цикла (удобно для медитации);
  • генератор MP3 — сохранить весь сеанс одним аудиофайлом;
  • режим «Таймер» — интервальный таймер для медитации без текста;
  • визуальные подсказки — сжатие текста до первых букв слов для тренировки памяти.

Dict.Dhamma.Gift​

Словарь палийского канона с несколькими источниками, навигация и интерфейс адаптированы для смартфонов и планшетов: DPD (Digital Pāḷi Dictionary, основной), Sutta-Vinaya Definitions and Similes, Gandhari Dictionary, PTS Dictionary, Buddhadust Glossology, Wisdom Library, словарь санскрита. Подробнее о режимах словаря — на отдельной странице Словарь. Открыть сайт словаря.

@DGift_bot — Telegram-бот и мини-приложения​

Наберите в любом чате или группе @Dhammagift_bot (или короткое имя @Dgift_bot), начните вводить слово на пали или номер текста — бот покажет варианты и даст ссылки на Чтение/Поиск и Словарь. Отдельные мини-приложения: поиск, чтение и словарь.

Общие принципы​

  • Разработано и оптимизировано в первую очередь для телефонов и планшетов, с полноценной поддержкой десктопа.
  • Приватность прежде всего: пользовательские данные не собираются — всё хранится в браузере (или синхронизируется анонимно по кодовой фразе).
  • Проект активно развивается, обратная связь приветствуется.
  • Всё можно установить офлайн/локально на Android, Windows и Mac.
