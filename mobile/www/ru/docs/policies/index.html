Политика конфиденциальности и условия использования

Конфиденциальность​

Мы придерживаемся принципа максимальной анонимности. Проект спроектирован так, чтобы использование функций поиска и чтения не требовало раскрытия личности пользователя.

Охватываемые продукты​

Сервисы Telegram

  • Telegram-боты: @Dhammagift_bot (основной бот для поиска по суттам и пали-словарю), @Dgift_bot (короткое имя бота).
  • Мини-приложения Telegram: поиск, чтение, словарь.

PWA- и TWA-приложения

  • Dhamma.Gift PWA — устанавливаемое прогрессивное веб-приложение.
  • Dhamma.Gift Android TWA — доступно в Google Play.
  • Dict.Dhamma.Gift PWA — специализированное словарное PWA.
  • Dict.Dhamma.Gift Android TWA — доступно в Google Play.

Браузерные расширения

  • Расширение для Chrome
  • Расширение для Firefox
  • Расширение для Microsoft Edge

Облачная синхронизация (опционально)​

Эта функция включается на сайте и/или в PWA/TWA-приложении Dhamma.gift только по желанию пользователя для сохранения настроек, избранного и истории между устройствами.

  • Инфраструктура — данные хранятся во внешней облачной базе данных Google Firebase.
  • Методы входа:
    • Анонимный вход — при использовании секретной фразы она хэшируется на вашем устройстве (SHA-256) перед отправкой. В базе хранится только анонимный идентификатор, исходная фраза не сохраняется.
    • Google-аккаунт — используется только ваш email для идентификации сессии. В базе хранится хэшированная запись, скрывающая ваш email.
  • Хранение данных — сохраняются только ваши закладки (Favorites), история поиска и настройки интерфейса. Эти данные доступны исключительно вам после авторизации.
  • Удаление — вы можете в любой момент полностью удалить все свои данные из облачной базы через кнопку «Delete Cloud Data» в меню синхронизации.

Обрабатываемые данные​

Продукты обрабатывают только минимальные технические данные, необходимые для основной функциональности:

  • Поиск — передаются только поисковые запросы, ссылки на тексты или выбранные слова для словаря.
  • Синхронизация — при использовании функции синхронизации обрабатываются метаданные об активных сессиях (тип ОС и браузера) для управления вашими устройствами.
  • Технические данные — базовая метаинформация запросов (IP-адрес, User-Agent), собираемая веб-серверами для защиты от атак.

Что мы НЕ собираем​

  • Личную информацию пользователей (за исключением email при входе через Google).
  • ID пользователей Telegram или истории чатов.
  • Историю посещений вне наших сервисов.
  • Постоянные идентификаторы для отслеживания (вне рамок выбранной пользователем сессии синхронизации).

Передача данных​

Все данные передаются только на наши сервисы или доверенную инфраструктуру:

  • dhamma.gift / dict.dhamma.gift — для поиска и чтения.
  • dpdict.net — для результатов пали-словаря.
  • Google Firebase — исключительно для обеспечения работы функции облачной синхронизации.

Данные пользователей не передаются третьим сторонам для маркетинговых или иных целей.

Хранение данных​

  • Без синхронизации — мы не храним поисковые запросы, слова или историю на серверах; все данные хранятся только локально в localStorage вашего браузера.
  • При синхронизации — данные (избранное, настройки, история) хранятся в облачной базе Google до тех пор, пока пользователь не решит их удалить.
  • Логи — технические логи серверов хранятся максимум 30 дней.

Обновления политики конфиденциальности​

Настоящая Политика конфиденциальности может периодически обновляться. Дальнейшее использование сервисов после вступления изменений в силу будет означать согласие с обновлённой политикой.

По всем вопросам обращайтесь на agiftofdhamma@gmail.com.

Последнее обновление: апрель 2026.

Условия использования​

Палийский корневой текст, традиционные комментарии и переводы, представленные здесь, взяты из проекта SuttaCentral (данные Bilara) и собственных кураторских переводов проекта Dhamma.gift, на условиях их соответствующих лицензий. Dhamma.gift не добавляет никаких дополнительных ограничений сверх тех, что уже несёт исходный материал.
