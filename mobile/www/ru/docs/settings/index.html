Настройки

Настоящая, живая страница настроек — ничего нажимать или искать на клавиатуре не нужно:

Быстрые настройки — отдельная панель прямо у поля поиска​

Кроме этой полной страницы есть вторая, лёгкая панель — «Быстрые настройки», значок с ползунками рядом с полем поиска (⚙︎-иконка слева от лупы). Она не дублирует страницу настроек, а даёт быстрый доступ к самому нужному прямо там, где вы сейчас работаете — на главной, в результатах поиска или в ридере, без перехода на отдельную страницу. Набор групп меняется в зависимости от того, где вы находитесь — вот все группы, которые в ней встречаются:

  • Где искать — те же 4 Никаи / Кхуддака Никая / Виная, что и «Где искать по умолчанию» ниже на этой странице, но меняет область поиска только для текущего запроса.
  • Словарь — какой режим словаря использовать (см. Словарь).
  • Контекст в цитатах — только на странице результатов: сколько строк показывать до/после найденной.
  • Вид выдачи — Тексты / Слова (только на странице результатов).
  • Чтение — Варианты чтения и Режим колонок (в ридере), Скрыть пунктуацию Pāḷi (везде, где есть текст на пали).
  • Скрипт для Деванагари — появляется только когда ридер в режиме «Деванагари» (см. Ридер).
  • Диакритика Pāḷi — кнопки со спецсимволами пали (ā ī ū ṁ ñ ṅ ṭ ḍ ṇ ḷ), клик вставляет символ прямо в поле поиска.

Изменения в «Быстрых настройках» сохраняются сразу — это те же настройки, что и на полной странице ниже, просто под рукой, без перехода никуда.

Общее​

  • Язык интерфейса — меню и подписи (не влияет на языки текстов).
  • Тема — светлая / тёмная / авто. Alt+T. (Хранится в localStorage.theme — том же ключе, которым для своего переключателя темы пользуется и этот сайт справки, поэтому переключение здесь или на этой странице держит обе темы синхронизированными «на лету», в рамках одного origin.)
  • Облако — синхронизация закладок, заметок и настроек между устройствами, см. Вход.

Чтение​

  • Языки для чтения — не только русский и английский: список из полутора десятков языков с числом доступных текстов у каждого. Первый выбранный — основной, от количества языков зависит режим отображения в ридере (см. Режимы чтения); порядок можно менять перетаскиванием чипов.

  • Система письма пали — ISO-латиница и другие системы письма (см. Систему письма пали в статье про Ридер). Отдельный переключатель решает, применяется ли выбор везде или только в режиме «Деванагари».

  • Размер текста — плюс/минус, тот же Alt+= / Alt+-, что и везде на сайте.

  • Показывать пунктуацию в пали — выключите, чтобы убрать запятые/кавычки и заменить точки/?/! вертикальной чертой — ближе к виду рукописей. Alt+.

Поиск​

  • Где искать по умолчанию — тот же чекбокс-список 4 Никаи / Кхуддака Никая / Виная, что и в «Быстрых настройках», но здесь — какое значение использовать по умолчанию для новых запросов (в самом поиске область по-прежнему можно поменять для одного конкретного запроса).
  • Языки для поиска — по умолчанию совпадают с языками для чтения; переключатель позволяет задать для поиска отдельный набор языков.
  • Строк контекста — сколько строк показывать до/после совпадения (числом, не кнопками — та же настройка, что «Контекст в цитатах» в Быстрых настройках).
  • Несколько слов — в любом порядке — уже видна в интерфейсе, но честно помечена как «пока не реализовано на сервере» — переключатель недоступен.

Словарь​

  • Dict.DG — общий выключатель словарной платформы (см. Словарь).
  • Режим — какое конкретно окно/вкладка открывается по клику на слово.
  • Искать выделенный текст автоматически — то же самое, что кнопка мультивыбора в ридере (Alt+J): выделили несколько слов — словарь ищет их сам, без клика по кнопке. Есть настройка задержки (3 или 5 сек).

Коренной текст пали​

Издание палийского текста для поиска и ридера. Сейчас поиск всегда идёт по Mahāsaṅgīti (MS); издания BJT, VRI и SIAM показаны в интерфейсе, но помечены «скоро» — пока недоступны.

Озвучка​

  • Ключ Google Cloud API — свой ключ для более качественного голоса (хранится только в этом браузере) — подробности в Голос / TTS.
  • Голос и скорость чтения — открывает отдельную панель (ту же, что значок настроек в самом плеере ридера, Alt+R) — см. Голос / TTS.

Данные​

  • История поиска и избранное — «Очистить» стирает их с этого устройства (хранятся локально, если вы не вошли в облако).
  • Все настройки — «Сбросить» возвращает всё на этой странице к значениям по умолчанию, не трогая историю, избранное и вход в облако.
