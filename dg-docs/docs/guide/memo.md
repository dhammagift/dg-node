# Memo

The "Memorize & Meditate" tool — build a custom audio session from any
text: precise slicing by period/comma/line, custom repetition counts and
pause durations, meditation gongs, MP3 export, a standalone interval-timer
mode, and a first-letter visual-cue mode for memorization. See also
[Voice / TTS](/voice-tts) for the simpler in-reader player.
