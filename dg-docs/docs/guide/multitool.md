# MultiTool

Dhamma.gift was built to gather the best resources on Dhamma and Pali —
texts, dictionaries, key websites, e-books and tools — in one place, so you
don't have to hunt for them one by one. That collection is the tool tiles
on the <SiteLink to="/">Dhamma.gift</SiteLink> home screen: **Read Pāḷi**,
**External** (other Pali editions), **AI & Dicts**, **Materials**, **Tools**
(the "Magic Button" Alt+Q dictionary opener, Aksharamukha script converter,
Sutta Diff, and more), **History**, and **Help**.

**Know a site, app, or resource that belongs here?** Tell us via
<SiteLink to="/#contacts">Contacts</SiteLink> — this list grows from
suggestions.

## Make it your own

The tiles aren't fixed — open the menu (☰, top right) for:

- **Add your own button** — label, address, an optional description (shown
  as a tooltip), and an icon (pick one or type your own emoji/symbol). The
  address can include `{{q}}`, which is replaced with whatever is in the
  search box — so a custom button can act as a one-click search on any
  external site.
- **Edit buttons** — hide, reorder, or rename the built-in tiles.

These customizations (your own buttons, hidden/reordered/renamed tiles) are
plain settings, so they sync across your devices the same way as favorites
and history — see [Settings](/settings-guide).
