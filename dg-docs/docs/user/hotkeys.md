# Keyboard shortcuts

Every shortcut the site has, in one place. They work on the home page, in search results and in
the reader. **Alt** shortcuts work even while the cursor is in the search field; on a Mac use
**Option** instead of Alt.

:::tip[Try them right here]
Click inside the window below (a real reader page), then press any shortcut from the tables.
:::

<AppFrame src="/mn1" title="Try the shortcuts: MN 1 in the reader" height={520} />

## Everywhere

| Shortcut | What it does |
|---|---|
| **Alt+M** | Open / close the menu (burger) |
| **Alt+S** | Quick settings |
| **Alt+P** or **Alt+Y** | Quick window (compass): favorites, history, key suttas |
| **Alt+H** | Help |
| **Alt+G** | Search history |
| **Alt+T** | Light / dark theme |
| **Alt+−** / **Alt+=** | Smaller / larger text |
| **Ctrl+Shift+1** | Switch the site language (English / Russian) |
| **Alt+1** | Outside the reader: switch the language, like the menu's EN/RU switch |
| **/** | Put the cursor into the search field |
| **Esc** | Close the open window, menu or notification |
| **Ctrl+Shift+F** or **Alt+Shift+F** | Find on the page |
| **Ctrl+1** | Home / search |
| **Ctrl+2** | Read suttas and Vinaya |
| **Ctrl+3** | Read by chapters |

## Reading

| Shortcut | What it does |
|---|---|
| **Ctrl+→** / **Ctrl+←** | Next / previous text |
| **Alt+1** … **Alt+7** | Reader modes (a second press of the current mode's key switches the language) |
| **Alt+Space** or **Alt+Z** | Show / hide the second language (Pali or translation) |
| **Alt+C** | One or two columns |
| **Alt+V** | Show / hide variant readings |
| **Alt+W** | Table of contents of the text |
| **Alt+L** | Pali script: Latin → Devanagari → Thai |
| **Alt+.** or **Alt+,** | Show / hide punctuation in Pali |
| **Alt+F** | Add to / remove from favorites |
| **Alt+R** | Read aloud: start / pause |

## Search results

| Shortcut | What it does |
|---|---|
| **Alt+X** or **Shift+Space** | Expand / collapse all results |

## Dictionary

| Shortcut | What it does |
|---|---|
| **Alt+A** | Dictionary on / off |
| **Alt+B** | Dictionary mode |
| **Alt+J** | Multi-select: look up the selected text automatically |
| **Alt+N** | Open the dictionary in a separate window, with the current word |

## Read-aloud player

Work while the player is open, without Alt/Ctrl:

| Key | What it does |
|---|---|
| **S** | Auto-scroll on / off |
| **1** … **4** | What to read: Pali · Pali then translation · translation · translation then Pali |
| **−** / **+** | Slower / faster |
| **R** | Normal speed |

:::note
In a text field, **Ctrl+←/→** and **/** keep their usual meaning (moving by words, typing a slash) —
only the Alt shortcuts are taken over there.
:::
