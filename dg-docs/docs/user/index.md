# Key Features

Dhamma.gift is a set of connected tools built around the Pali Canon (Sutta
and Vinaya) and its translations: search, a line-by-line reader, a Pali
dictionary, and a text-to-speech player, tied together so that finding a
passage, reading it with a translation, listening to it, and memorizing it
are all one continuous workflow rather than separate apps.

## Dhamma.Gift — a multi-tool / one-window portal

<img src="/assets/img/multi-tool-512x512.png" alt="Dhamma multi-tool logo" style={{float: 'left', marginRight: '15px', maxWidth: '96px'}} />

Dhamma.gift was built to gather the best online resources on Dhamma and
Pali in one place — texts, dictionaries, key websites, e-books and tools.
They're all collected in the "link collection" tucked into the toolbar
under the search box — see [MultiTool](/multitool). If something's
missing, let us know!

<div style={{clear: 'both'}} />

## Find.Dhamma.Gift — Sutta and Vinaya search

<img src="/assets/img/find-dhamma-512x512.png" alt="Sutta and Vinaya search logo" style={{float: 'left', marginRight: '15px', maxWidth: '96px'}} />

A tool for anyone who wants to systematically work through the Pali
Suttas and Vinaya. Results come back in convenient tables with basic and
advanced filtering, several sort orders, and grouping by text or by word.
Gives direct access to the Pali texts with a line-by-line English and
Russian translation, plus external links to Theravada.ru, Theravada.su,
DigitalPaliReader.online, TheBuddhasWords.net and SuttaCentral.net. See
[Search](/search-guide).

<div style={{clear: 'both'}} />

## Dhamma.Gift Read — line-by-line reading with a pop-up dictionary

<img src="/assets/img/dgsanhkalogo.png" alt="Dhamma.Gift Read logo" style={{float: 'left', marginRight: '15px', maxWidth: '96px'}} />

- One of the largest collections of line-by-line Pali↔Russian texts
  anywhere: AN, DN, MN, SN, KN (Snp, Ud, Iti, Dhp, Thag, Thig), and parts
  of the Vinaya Vibhaṅga.
- The only site with a built-in, online Russian version of the Digital
  Pāḷi Dictionary (DPD) — a click-to-look-up popup dictionary.
- **Multilingual mode** — Pali, English and Russian translations shown
  together at once.
- **Favorites & History** — a personal library of texts for quick access.
- **Reading Progress** — resume exactly where you left off.
- **Cloud Sync** — favorites, history, reading progress and preferences
  (languages, theme, font) synced across devices, anonymously via a secret
  passphrase — no email or registration required. See [Login](/login).
- Full online DPD dictionary lookup, plus integration with DictTango
  (Android), Mdict (iOS), GoldenDict-NG (desktop), and Dharmamitra.org for
  deep grammatical analysis.
- **Smart TOC** — fast navigation that adapts to your selected languages.
  See [TOC Navigator](/toc).
- **Reading modes** — no-punctuation, memorization mode, non-Latin script
  assistant (Devanagari, Thai, ...), and other modes. See
  [Reader](/read).
- **Voice integration** — jump straight from reading to listening or
  memorizing any phrase. See [Voice / TTS](/tts).
- **Keyboard shortcuts** for fast navigation.

## Dhamma.Gift Voice — a unified text + audio ecosystem

<img src="/assets/img/albumart512.png" alt="Dhamma.Gift Voice logo" style={{float: 'left', marginRight: '15px', maxWidth: '96px'}} />

A set of tools for voicing canonical texts, built right into the reading
flow instead of living in a separate playback app.

**1. Reading Mode player** — built straight into the sutta interface:
- alternates Pali and translation in either order;
- **pauses between phrases** — an adjustable gap for reflection or reading
  aloud along with it;
- **A-B loop** — repeat any passage for focused listening;
- built-in device voices (e.g. Android's Sanskrit voice reads Pali
  reasonably well) — works offline;
- Google voices — a much larger, higher-quality selection than the
  built-in ones;
- auto-scroll and highlighting of the current phrase.

**2. Memorize & Meditate ([Memo](/memo))** — memorize texts by heart or
build audio meditations:
- a highly flexible TTS setup — customize the voicing for any text;
- fine-grained slicing into blocks by period, comma, or line;
- adjustable repeat count and pause length per phrase;
- an end-of-cycle gong (handy for meditation);
- an MP3 generator — save the whole session as one audio file;
- "Timer" mode — a plain interval timer for meditation with no text;
- visual hints — compressing text down to first letters, for memory
  training.

## Dict.Dhamma.Gift

<img src="/assets/svg/dg-logo-dark.svg" alt="Dict.Dhamma.Gift logo" style={{float: 'left', marginRight: '15px', maxWidth: '96px'}} />

A multi-source Pali Canon dictionary, with navigation and an interface
built for phones and tablets: [DPD](https://digitalpalidictionary.github.io/)
(Digital Pāḷi Dictionary, the core), Sutta-Vinaya Definitions and Similes,
the Gandhari Dictionary, PTS Dictionary, Buddhadust Glossology, Wisdom
Library, and a Sanskrit dictionary. More on the dictionary modes on the
dedicated [Dictionary](/dictionary) page. Open the
[dictionary site](https://dict.dhamma.gift).

## General principles

- Built and optimized for phones and tablets first, with full desktop
  support.
- Privacy first: no user data is collected — everything is stored in the
  browser (or synced anonymously via passphrase).
- Actively developed; feedback is welcome.
- Everything can be installed offline/locally on Android, Windows and Mac.
