# Dhamma.Gift Full

A second app, currently in development: the same site, but fully
offline — all texts, translations and the dictionary are stored right on
the device (except for functions that are inherently online, like Google
voices or external dictionaries — those only work with an internet
connection on the site too). Same shortcuts and "Share to Search" as in
[Dhamma.Gift online](/dhamma-gift-online), described in more detail on
["PWA: install straight from the browser"](/pwa).

A download link will appear here once the app is ready.
