# Key Features

Dhamma.gift is a set of connected tools built around the Pali Canon (Sutta
and Vinaya) and its translations — search, a line-by-line reader, a Pali
dictionary, and a text-to-speech player, tied together so that finding a
passage, reading it with a translation, hearing it, and memorizing it are
all one continuous workflow rather than separate apps.

## Dhamma.Gift — a multi-tool / one-window portal

A single entry point linking Search, Read, History, Dictionary and other
tools without leaving the page.

## Find.Dhamma.Gift — Sutta and Vinaya search

grep-style search across the Pali root text and its translations, with
context lines, regular expressions, and per-nikaya/per-sutta scoping. See
[Search](/search-guide).

## Dhamma.Gift Read — line-by-line reading with a pop-up dictionary

- **Favorites & History** — a personal library of texts for quick access.
- **Reading Progress** — resume exactly where you left off.
- **Cloud Sync** — favorites, history, reading progress and preferences
  (languages, theme, font) synced across devices, anonymously via a secret
  passphrase — no email or registration required.
- Full online DPD dictionary lookup, plus integration with DictTango
  (Android), Mdict (iOS), GoldenDict-NG (desktop), and Dharmamitra.org for
  deep grammatical analysis.
- **Smart TOC** — fast navigation that adapts to your selected languages.
  See [TOC Navigator](/toc-navigator).
- **Reading modes** — no-punctuation, memorization mode, non-Latin script
  assistant (Devanagari, Thai, ...), and other modes. See
  [Reader](/reader).
- **Voice integration** — jump straight from reading to listening or
  memorizing any phrase. See [Voice / TTS](/voice-tts).
- **Keyboard shortcuts** for fast navigation.
- One of the largest line-by-line Pali↔Russian text collections available;
  covers AN, DN, MN, SN, KN (Snp, Ud, Iti, Dhp, Thag, Thig) and parts of the
  Vinaya Vibhaṅga, alongside a Russian DPD dictionary integration.

## Dhamma.Gift Voice — a unified text + audio ecosystem

- **Reading Mode player** — listen to Pali and translations while following
  the text, alternate languages, set pauses between phrases, loop a
  sentence (A-B loop), use built-in device voices (offline) or Google
  Voices, with auto-scroll and phrase highlighting.
- **Memorize & Meditate** — a dedicated tool for memorizing texts or building
  audio meditations: precise slicing by period/comma/line, custom
  repetition counts and pause durations, meditation gongs, MP3 export, a
  standalone interval-timer mode, and a first-letter visual-cue mode for
  memory training.

## Dict.Dhamma.Gift

The DPD (Digital Pāḷi Dictionary) with an interface improved for mobile use.

## @DGift_bot — Telegram bot & Mini Apps

Search suttas and the Pali dictionary from any Telegram chat via
`@Dhammagift_bot` / `@DGift_bot`, or use the dedicated Mini Apps for
[search](http://t.me/dhammagift_bot/find), [reading](http://t.me/dhammagift_bot/read)
and the [dictionary](http://t.me/dhammagift_bot/dict).

## Browser extensions

Sutta search and the Pali pop-up dictionary on any website (Chrome, Edge,
Firefox, Opera; a Tampermonkey script is available too).

## General principles

- Built and optimized for phones and tablets first, with full desktop
  support.
- Privacy first: no user data is collected — everything is stored in the
  browser (or synced anonymously via passphrase).
- Actively developed; feedback is welcome.
- Everything can be installed offline/locally on Android, Windows and Mac.
