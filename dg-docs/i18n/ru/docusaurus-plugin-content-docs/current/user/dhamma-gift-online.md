# Dhamma.Gift online

<div style={{margin: '1rem 0'}}>
  <a href="https://play.google.com/store/apps/details?id=gift.dhamma.twa"><img src="/assets/img/buttons/google-play-cta.png" alt="Dhamma.Gift online в Google Play" style={{maxWidth: '220px'}} /></a>
</div>

Android-приложение в Google Play. Это буквально весь сайт целиком (та же
страница поиска и ридер, без урезаний), просто в собственном окне, плюс
два системных бонуса — ярлыки быстрого доступа и «Поделиться, чтобы
найти» (выделили слово в любом приложении → «Поделиться» → Dhamma.Gift →
готовый поиск). Как устроены эти два бонуса — на отдельной странице
[«PWA: ярлыки и Sharing API»](/pwa).

Второе, полностью офлайн-приложение — [Dhamma.Gift Full](/dhamma-gift-full)
(пока в разработке).
