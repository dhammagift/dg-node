## Основы

**Совет #0.** Поиск производится на пали, русском, английском и тайском в
материалах SuttaCentral.net и дополнительно thebuddhaswords.net — если
того или иного перевода там нет, здесь его тоже не будет. Логика поиска:
если вы ищете на русском — поиск идёт только в русских переводах; на
тайском — сначала пали, потом тайские переводы; на латинице — сначала
пали, потом английские переводы tbw, потом построчные переводы
Suttacentral.net.

**Совет #1.** Для поиска на пали можно печатать латинскими буквами —
варианты слов, встречающихся в четырёх никаях (ДН, МН, СН, АН), будут
предлагаться автоматически. Специальные символы (ā ī ū ḍ ḷ ṁ ṇ ṅ ñ ṭ) можно
скопировать из памятки по RegEx (иконка-шестерёнка).

**Совет #2. Кхуддака Никая.** Поиск по умолчанию идёт по ДН, МН, СН, АН.
Опция `-kn` добавляет к поиску Дхаммападу, Удану, Итивуттаку, Суттанипату,
Тхерагатху, Тхеригатху (остальные книги КН не участвуют в поиске даже с
`-kn` — для Джатак и прочего используйте другие ресурсы).
  - `-kn jamm` — искать по ДН/МН/СН/АН + перечисленным книгам КН.
  - `jamm` — искать только по ДН/МН/СН/АН.

**Совет #3. Виная.** Добавьте `-vin`, чтобы искать в Винае, например
`-vin cetana`.

**Совет #4.** Если результатов слишком мало — попробуйте искать по корню
слова, без приставки или окончания.

**Совет #5.** Делайте упор на пали — это язык, на котором записаны самые
древние тексты, связанные с Дхаммой; Будда не говорил ни на русском, ни на
английском.

**Совет #6.** Результаты поиска на пали — это таблица совпадений по
Суттам/Текстам с цитатами и отдельная таблица по словам. Используйте обе.
Для других языков таблица по словам тоже строится, но может работать
менее точно.

**Совет #7.** Минимальная длина запроса — 3 символа, но чем длиннее и
специфичнее шаблон, тем точнее результат.

**Совет #8.** В пали часто есть несколько разных слов там, где в
русском/английском — одно (например, для «змеи»); поиск на пали
раскрывает различия, которые перевод стирает.

**Совет #9.** Если запрос завершается ошибкой из-за таймаута, попробуйте
более длинный или более специфичный шаблон.

**Совет #10. Быстрые переходы.** Введите идентификатор сутты (в формате
suttacentral.net) вместо поискового запроса — вместо поиска вы перейдёте
сразу к палийскому тексту, с быстрым переключением на построчный
английский перевод. Работает для ДН, МН, СН, АН, перечисленных книг КН и
Винаи.

**Колонка «Mtphr».** Подсчитывает совпадения по всему тексту (без привязки
к вашему запросу) по шаблону
`seyyathāpi|adhivacan|ūpama|opama|opamma`, игнорируя
`adhivacanasamphass|adhivacanapath|ekarūp|tathārūpa|āmarūpa|\brūpa|evarūpa|\banopam|\battūpa|\bnillopa|opamaññ`.
Нашли другие критерии — создайте issue на GitHub.

## Работа с результатами

- **Клик в конце строки с пали** (курсор меняется со стрелки на палец) —
  перейти в ридер сразу на эту строку.
- **✦** — невидимая ссылка в начале и в конце фрагмента цитаты, чтобы
  открыть текст ридера с нужного места.
- Поле **Search** в таблице — простая фильтрация уже показанных
  результатов; **Custom Search Builder** внизу страницы — сложная
  фильтрация по нескольким условиям.
- **Экспорт** — выгрузка результатов в формате, удобном для ИИ или анализа.
- Кнопка **«Слова»** переключает таблицу на результаты, агрегированные по
  словам, а не по суттам.

## Колонки и ссылки таблицы

- **Sutta** — индекс текста (например, `sn56.11`, `dn22`, `an10.46`).
- **Title** — название текста.
- **Words** — совпавшие слова в тексте.
- **Count** — количество совпадений в тексте, включая варианты.
- **Type** — `4 Никаи` (Дигха/Мадджхима/Саньютта/Ангуттара), `Кхуддака Никая`
  (все книги КН) или `Виная` (все тексты, относящиеся к Винае).
- **Quote** — цитата с найденным словом.
- **Links** — Pi (читать на Dhamma.Gift Read), En (TheBuddhasWords.net), Ru
  (Theravada.ru или Theravada.su, когда доступно).

Аббревиатуры изданий (`ms`, `pts1ed`, `sya-all`, `mr` и т.п.) — смотрите
[Edition Abbreviations](pathname:///assets/texts/abbr.html) или
[список SuttaCentral](https://suttacentral.net/abbreviations?lang=ru).

## Для продвинутых

**Совет #1.** Опция применима только для поиска на пали или английском!
Чтобы найти слово в определённой сутте/самьютте/никае: `Sn17.*seyyathāpi`
выведет все метафоры и сравнения из Sn17. Для нескольких слов в кавычках:
`"Sn51.*(seyyathāpi|adhivacan|ūpama|opama)"`.

**Совет #2.** Для вариаций используйте `[]`: `nand[iī]` найдёт и `nandi`, и
`nandī`. По умолчанию буква «е» автоматически расширяется до `[ёе]`; чтобы
искать только «е», используйте `[е]` (для «ё» доп. символы не нужны).

**Совет #3.** Чтобы найти слово, начинающееся/заканчивающееся определённым
шаблоном, используйте `\b`: `\bkummo\b` найдёт только `kummo`, пропустив
`kummova` и другие совпадения.

**Совет #4.** Чтобы исключить один шаблон из результатов другого,
используйте `-exc`: `dundubh -exc devadundubh` найдёт слова вида `dundubh`,
но без `devadundubh`.

**Совет #5.** Поддерживаются полноценные регулярные выражения GNU
`grep -E` (с корректным экранированием). ИИ может сгенерировать шаблон —
ссылки есть в памятке по RegEx в настройках поиска.

**Совет #6.** Результаты выводятся с помощью
[DataTables](https://datatables.net/).

**Совет #7. Подборки.** В кавычках можно собрать произвольную подборку:
`"sn42.8|sn20.5"` выведет обе сутты полностью в одну таблицу; `"Sn20.1"`
выведет Sn20.1, Sn20.10, Sn20.11 и т.д.; `"Sn20.1\b"` — только Sn20.1.

**Как работает опция «Опр» (определение).** Запускается фиксированный
шаблон `grep -E -A1`, настроенный на «определяющие» формулировки (`X
nāma`, числительная лексика для Ан1–Ан11, `Seyyathāpi.*X`, вопросительные
конструкции вида `Kiṁ...vadeth`, `vuccati` и т.п.), с исключением каталогов
комментариев (`ab, bv, cnd, cp, ja, kp, mil, mnd, ne, pe, ps, pv, tha-ap,
thi-ap, vv`). Нашли другие критерии — создайте issue на GitHub.
