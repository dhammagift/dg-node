## Панель инструментов над результатами

<img src={SearchToolbar} alt="Кнопки над таблицей результатов поиска" style={{maxWidth: 700, display: 'block', margin: '0 auto 1.5rem'}} />

- **Saṁvaṭṭo / Vivaṭṭo** — да, подписи буквально на пали («сворачивание» /
  «разворачивание») — разворачивает или сворачивает цитаты во всех строках
  таблицы разом (то же самое, что и Shift+Space).
- **Слова** — переключает таблицу на список найденных слов вместо списка
  текстов.
- **Словарь** (Alt+A) — вкл/выкл всплывающий словарь по клику на слово.
- **1/2 колонки** — переключает цитаты между одной широкой колонкой и
  палийский+перевод рядом.
- **Отметки** — добавляет колонку с чекбоксом «прочитано» для каждой
  строки. Это отметки конкретно по текущей выдаче (запрос + область
  поиска), а не по сутте вообще — начав тот же поиск заново, увидите те же
  отметки, но это не то же самое, что общий прогресс чтения сутты.
- **Помощь** — открывает эту же страницу.

Прямо под полем ввода при необходимости появляется ссылка **«варианты»** —
если у искомого слова есть орфографические варианты написания в текстах,
она ведёт к их списку.

## Основы

:::info[На каких языках ищет поиск]
Поиск идёт по палийскому корневому тексту и по переводам — обычно
нескольких разных переводчиков на каждый язык (по умолчанию русский и
английский, `langs=ru,en`). Логика зависит от того, каким письмом набран
запрос: кириллица (например, `сострадание`) — поиск идёт только по
русским переводам; латиница или пали с диакритикой (`kacchapa`, `karuṇā`)
— сначала ищется в палийском тексте, и только если там совпадений не
нашлось, поиск повторяется по нерусским переводам (обычно английским).
:::

**Совет #1.** Для поиска на пали можно печатать латинскими буквами без
диакритики (`kacchapa`) — специальные символы (ā ī ū ḍ ḷ ṁ ṇ ṅ ñ ṭ) для
точного запроса можно скопировать из [Памятки по
RegEx](#памятка-по-regex--попробуйте-вживую) ниже.

**Совет #2. Где искать.** По умолчанию поиск идёт по 4 Никаям (ДН, МН, СН,
АН) плюс части Кхуддака Никаи (Дхаммапада, Удана, Итивуттака, Суттанипата,
Тхерагатха, Тхеригатха). Это можно изменить в панели **«Быстрые
настройки»** (кнопка с ползунками рядом с полем поиска) — там же
включается поиск по Винае и выбирается, какие ещё книги Кхуддака Никаи
подключить:

<img src={SearchQuickSettings} alt="Панель «Быстрые настройки» — выбор области поиска" style={{maxWidth: 345, display: 'block', margin: '0 auto 1.5rem'}} />

В той же панели настраивается количество строк контекста до/после цитаты
(«Контекст в цитатах») — тот же параметр, что и кнопки `lb`/`la` в API.

**Совет #3.** Если результатов слишком мало — попробуйте искать по корню
слова, без приставки или окончания.

**Совет #4.** Делайте упор на пали — это язык, на котором записаны самые
древние тексты, связанные с Дхаммой; Будда не говорил ни на русском, ни на
английском.

**Совет #5.** Результаты поиска на пали — это таблица совпадений по
Суттам/Текстам с цитатами и отдельная таблица по словам. Используйте обе.
Для других языков таблица по словам тоже строится, но может работать
менее точно.

**Совет #6.** Минимальная длина запроса — 3 символа, но чем длиннее и
специфичнее шаблон, тем точнее результат.

**Совет #7.** В пали часто есть несколько разных слов там, где в
русском/английском — одно (например, для «змеи»); поиск на пали
раскрывает различия, которые перевод стирает.

**Совет #8.** Если запрос завершается ошибкой из-за таймаута, попробуйте
более длинный или более специфичный шаблон.

:::tip[Быстрый переход по id сутты]
Введите идентификатор сутты (в формате suttacentral.net, например `dn22`)
вместо поискового запроса — вместо поиска вы сразу попадёте в ридер на
эту сутту. Работает для ДН, МН, СН, АН, перечисленных книг КН и Винаи.
:::

**Колонка «Mr».** Подсчитывает совпадения по всему тексту (без привязки
к вашему запросу) по шаблону
`seyyathāpi|adhivacan|ūpama|opama|opamma`, игнорируя
`adhivacanasamphass|adhivacanapath|ekarūp|tathārūpa|āmarūpa|\brūpa|evarūpa|\banopam|\battūpa|\bnillopa|opamaññ`.
Нашли другие критерии — создайте issue на GitHub.

## Работа с результатами

- **Клик в конце строки с пали** (курсор меняется со стрелки на палец) —
  перейти в ридер сразу на эту строку.
- **✦** — невидимая ссылка в начале и в конце фрагмента цитаты, чтобы
  открыть текст ридера с нужного места.
- Поле **Search** в таблице — простая фильтрация уже показанных
  результатов; **Custom Search Builder** внизу страницы — сложная
  фильтрация по нескольким условиям.
- **Экспорт** — выгрузка результатов в формате, удобном для ИИ или анализа.
- Кнопка **«Слова»** переключает таблицу на результаты, агрегированные по
  словам, а не по суттам.
- Под таблицей — ссылки на отдельные вспомогательные инструменты: **Make
  List** (собрать список из произвольного текста), **List Diff** (сравнить
  два списка ссылок) и **Sutta Diff** (сравнить редакции сутты) — каждый
  открывается отдельной страницей.

## Колонки и ссылки таблицы

- **Sutta** — индекс текста (например, `sn56.11`, `dn22`, `an10.46`).
- **Title** — название текста.
- **Words** — совпавшие слова в тексте.
- **Count** — количество совпадений в тексте, включая варианты.
- **Type** — `4 Никаи` (Дигха/Мадджхима/Саньютта/Ангуттара), `Кхуддака Никая`
  (все книги КН) или `Виная` (все тексты, относящиеся к Винае).
- **Quote** — цитата с найденным словом.
- **Links** — Pi (читать на Dhamma.Gift Read), En (TheBuddhasWords.net), Ru
  (Theravada.ru или Theravada.su, когда доступно).

Аббревиатуры изданий (`ms`, `pts1ed`, `sya-all`, `mr` и т.п.) — смотрите
[Edition Abbreviations](pathname:///assets/texts/abbr.html) или
[список SuttaCentral](https://suttacentral.net/abbreviations?lang=ru).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+A | Вкл/выкл словарь (клик по слову активирует [DPD](pathname:///assets/common/dictHelpRu.html)) |
| Alt+S | Показать/скрыть настройки |
| Alt+T | Тёмная / светлая / авто тема |
| Alt+Space, Alt+Z | Показать/скрыть пали или другие языки в результатах |
| Shift+Space | Свернуть/развернуть все результаты поиска |
| / | Активировать поле ввода Search Builder |

## Для продвинутых

**Совет #1.** Опция применима только для поиска на пали или английском!
Чтобы найти слово в определённой сутте/самьютте/никае: `Sn17.*seyyathāpi`
выведет все метафоры и сравнения из Sn17. Для нескольких слов в кавычках:
`"Sn51.*(seyyathāpi|adhivacan|ūpama|opama)"`.

**Совет #2.** Для вариаций используйте `[]`: `nand[iī]` найдёт и `nandi`, и
`nandī`.

**Совет #3.** Чтобы найти слово, начинающееся/заканчивающееся определённым
шаблоном, используйте `\b`: `\bkummo\b` найдёт только `kummo`, пропустив
`kummova` и другие совпадения.

**Совет #4.** Поддерживаются полноценные регулярные выражения GNU
`grep -E` (с корректным экранированием). ИИ может сгенерировать шаблон —
подсказки и ссылки есть в [Памятке по RegEx](#памятка-по-regex--попробуйте-вживую) ниже.

**Совет #5.** Результаты выводятся с помощью
[DataTables](https://datatables.net/).

**Совет #6. Подборки.** В кавычках можно собрать произвольную подборку:
`"sn42.8|sn20.5"` выведет обе сутты полностью в одну таблицу; `"Sn20.1"`
выведет Sn20.1, Sn20.10, Sn20.11 и т.д.; `"Sn20.1\b"` — только Sn20.1.
