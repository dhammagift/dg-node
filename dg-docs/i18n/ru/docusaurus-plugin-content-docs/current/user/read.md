# Ридер

Открывайте любую сутту напрямую по её id (`dn22`, `mn139`, `sn56.11`,
`an4.180`) — поиск не нужен. Попробуйте прямо здесь (это настоящий ридер, а
не демо-копия — кликайте, переключайте режимы, меняйте шрифт):

## Режимы чтения

Режимы описаны в `configs/reader/mode-table.json` и определяют, какие
колонки показываются:

| Режим | Что показывает |
|---|---|
| `single` | Одна языковая колонка (пали или один перевод) |
| `multiTran` | Два переводчика одного языка рядом |
| `multiLang` | Пали + перевод вместе |
| `memorize` | Раскладка для заучивания |
| `devanagari` | Двойное письмо (например, деванагари рядом с латиницей) |

Переключайте режимы клавишами **Alt+1** … **Alt+5**. Повторное нажатие той
же клавиши режима циклически переключает доступные языки/переводчиков
внутри режима.

## Полезные горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+1 … Alt+5 | Переключить режим чтения (см. таблицу выше); повтор — цикл языков |
| Alt+C | Переключить 1-колоночный / 2-колоночный вид |
| Alt+L | Переключить систему письма пали (ISO / деванагари / тайская) |
| Alt+T | Переключить тему (светлая/тёмная) |
| Alt+F | Переключить избранное |
| Alt+R | Переключить голосовой плеер / TTS — см. [Голос / TTS](/tts) |
| Alt+W | Открыть TOC — см. [Навигатор TOC](/toc) |
| Alt+N | Открыть словарь в новом окне |
| Alt+Space / Alt+Z | Переключить язык интерфейса |
| Клик по сегменту | Скопировать цитату + ссылку на неё |
| Правый клик / долгое нажатие | Скопировать только ссылку |
