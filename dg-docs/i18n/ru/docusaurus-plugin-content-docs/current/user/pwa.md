# PWA: ярлыки и «Поделиться, чтобы найти»

Dhamma.gift можно установить как приложение прямо из браузера (PWA —
Progressive Web App) — без App Store/Google Play, одной кнопкой:

<div style={{margin: '1rem 0'}}>
  <SiteLink to="/"><img src="/assets/img/buttons/pwa-cta.png" alt="Установить как PWA" style={{maxWidth: '220px'}} /></SiteLink>
</div>

После установки на телефоне или компьютере появляется отдельная иконка — как
у обычного приложения, без адресной строки браузера. Ровно тот же сайт,
только в собственном окне. У установленного приложения на Android (и у
нативного [Dhamma.Gift online](/dhamma-gift-online)) есть два бонуса поверх
обычного сайта — ярлыки и «Поделиться, чтобы найти».

## Ярлыки (Shortcuts)

Долгое нажатие на иконку приложения на главном экране (или правый клик на
иконке в панели задач на десктопе) открывает меню быстрых ссылок — минуя
главную страницу, сразу в нужное место:

- **Dhamma.Gift TOC** → оглавление текстов
- **Dict.Dhamma.Gift** → словарь
- **Bhikkhu Patimokkha** / **Bhikkhuni Patimokkha** → монашеский устав
- **Aksharamukha.com** / **Dharmamitra.org** → внешние инструменты для
  транслитерации и грамматического разбора

Список задан в `manifest.json` (`shortcuts`) — тот же самый файл управляет
и обычным PWA-приложением, и нативным Android-приложением, так что ярлыки
не нужно поддерживать отдельно в двух местах.

## «Поделиться, чтобы найти» (Share to Search)

Главный сценарий: **вы читаете что угодно** — статью, книгу в другом
приложении, сообщение — **встречаете слово или фразу на пали**, выделяете
её и через системное меню «Поделиться» отправляете в Dhamma.Gift. Приложение
сразу открывается с готовым поиском по этой фразе — без копирования в буфер,
без ручного перехода на сайт, без вставки в строку поиска.

Технически это стандартный Web Share Target: `manifest.json` объявляет
`share_target` с параметром `text → q`, и Dhamma.Gift появляется в системном
списке «Поделиться» на любых страницах и в любых приложениях, где есть текст.

### Где это работает

| Где | Ярлыки | Поделиться, чтобы найти |
|---|---|---|
| Установленный PWA на Android (Chrome/Edge) | ✅ | ✅ |
| [Dhamma.Gift online](/dhamma-gift-online) (Google Play) | ✅ | ✅ |
| [Dhamma.Gift Full](/dhamma-gift-full) (готовится, офлайн) | ✅ | ✅ (нативно, тот же принцип) |
| Установленный PWA на Windows/Mac (Chrome/Edge) | ✅ | частично (зависит от ОС) |
| iPhone / iPad (Safari, PWA или обычный сайт) | — | — |

На iOS Safari пока не поддерживает Web Share Target для установленных
веб-приложений — на iPhone тот же результат («выделил и сразу нашёл на
Dhamma.gift») удобнее получить через [браузерное расширение](/browser-extension)
(для настольного Safari через Tampermonkey-скрипт) или через
[Telegram-бота](/telegram-bot).

:::tip[Один и тот же механизм везде]
И в Google Play-приложении **Dhamma.Gift online**, и в будущем офлайн
**Dhamma.Gift Full** ярлыки и «Поделиться» — не отдельная урезанная
функция, а буквально полный сайт (то же самое `search/index.html` целиком,
без каких-либо сокращений), поверх которого добавлены эти два системных
удобства. Разница между сайтом и приложением — только в них.
:::
