# Вход

Для Dhamma.gift не нужен аккаунт или email. «Вход» здесь означает
анонимную облачную синхронизацию: задайте секретную кодовую фразу — и ваше
избранное, история, прогресс чтения и настройки будут синхронизироваться
между устройствами. Любой, кто знает ту же фразу, получит доступ к тем же
синхронизированным данным — относитесь к ней как к паролю.
