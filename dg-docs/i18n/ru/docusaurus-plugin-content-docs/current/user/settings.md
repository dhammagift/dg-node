# Настройки

Настоящая, живая страница настроек — ничего нажимать или искать на
клавиатуре не нужно:

<AppFrame src="/settings/" title="Живая страница настроек" height={700} />

## Что означает каждая настройка

- **Система письма** — пали: ISO/латиница, деванагари или тайская. Цикл —
  **Alt+L**.
- **Режим словаря** — как ведёт себя всплывающий словарь: отдельная
  страница (русский), полный попап, новое окно, компактный,
  DharmaMitra, только поиск, либо внешний словарь (DictTango, Mdict,
  GoldenDict-NG).
- **Убрать пунктуацию** — убирает пунктуацию из палийского текста (удобно
  для заучивания). **Alt+.** или **Alt+M**.
- **Режим чтения по умолчанию** — какой режим (см. [Ридер](/read))
  открывается по умолчанию.
- **Размер шрифта** — **Alt+=** / **Alt+-**.
- **Тема** — светлая / тёмная / авто. **Alt+T**. (Выбор хранится в
  `localStorage.theme` — том же ключе, которым для своего переключателя
  светлой/тёмной темы пользуется и этот сайт справки, поэтому переключение
  здесь или на этой странице держит обе темы синхронизированными
  «на лету», в рамках одного origin.)
- **Мультивыбор для словаря** — выбрать несколько слов сразу. **Alt+J**.
- **TTS** — включение голоса и скорость воспроизведения. См.
  [Голос / TTS](/tts).
- **Сбросить все настройки** — очищает всё, кроме избранного, истории и
  ключей облачной синхронизации (с подтверждением).

## Связанные горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+Space / Alt+Z | Переключить язык интерфейса |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | Главная / Чтение / «чтение по главам» |
| Ctrl+Shift+1 | Язык сайта |
| Alt+G | Переключить панель истории |
| Alt+8 | Режим отображения ml/th |
