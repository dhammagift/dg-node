# Редактор переводов

Черновая версия. CAT-редактор (Computer-Assisted Translation) для
построчного перевода текстов Пали-канона — удобный ввод, быстрые шаблоны
и два режима работы с текстом.

<AppFrame src="/assets/lbl.html?q=mn1&demo=1" title="Редактор переводов" height={650} />

:::info[В этой демонстрации кнопка «Сохранить» отключена]
Инструмент встроен здесь как полностью настоящий (не копия), поэтому
сохранение — и локальное скачивание, и отправка на сервер — здесь
намеренно не работает, чтобы никто не мог случайно (или специально)
перезаписать этим черновиком реальный файл перевода. Клик по «Сохранить»
здесь просто покажет предупреждение. Чтобы сохранять по-настоящему —
откройте инструмент по прямой ссылке
[/assets/lbl.html](pathname:///assets/lbl.html).
:::

## Панель инструментов

- **◀ ▶** — предыдущий/следующий текст.
- **Номер сутты** — ввод индекса (например, `sn56.11`, `an3.70`), с
  автоопределением, существует ли уже перевод.
- **Язык источника** — выбор языка исходного файла.
- **DT.org / DG** — открыть текущий текст на DigitalPaliReader.online / на
  Dhamma.Gift.
- **Обновить** — перезагрузить перевод из источника.
- **Найти/Заменить** — окно поиска и замены (для `(`, `)`, `[`, `]` нужно
  экранирование: `\(`, `\)`, `\[`, `\]`).
- **Формат** — авто-форматирование переносов строк.
- **Очистить** — очистить поле ввода.
- **Открыть файл / Загрузить с сервера** — открыть ранее сохранённый черновик.
- **Сохранить** — выгрузить перевод в JSON.
- **Diff Checker** — внешний инструмент сравнения версий текста.

## Два режима ввода

### Табличный режим

Двухколоночная таблица (Текст | Перевод) — каждая строка редактируется
отдельно.

- Клик по ячейке — редактировать.
- Значок 🔗 — перейти к этой строке в режиме быстрого ввода.
- **↑ / ←** — переход на ячейку выше.
- **↓ / →** — переход на ячейку ниже.
- **Enter** — добавить пустую строку или перенести текст на новую строку.
- **Ctrl+Enter** — перенести текст в начало следующей строки.
- **Backspace** в начале строки — объединить с предыдущей строкой.
- **Delete** в конце строки — объединить со следующей строкой.

### Режим быстрого ввода

Одно большое текстовое поле — весь перевод сразу, синхронизируется с
таблицей на лету.

- **Ctrl+Q** — выделить список строк и объединить их в одну строку.
- **Ctrl+F / Ctrl+H** — поиск/замена (то же экранирование `()`/`[]`, что и
  в панели инструментов).

## Быстрые шаблоны

Кнопки для часто повторяющихся формул канона — вставляют текст в позицию
курсора одним кликом: **4nt** / **4nt short** (Четыре Благородные Истины,
полная и краткая формула), **n8p** / **n8p short** (Благородный
Восьмеричный Путь), **Thus said…** (заключительная формула сутты), а
также тире, кавычки-ёлочки и перевёрнутый вопросительный знак для
пунктуации.

## Настройки

Имя переводчика (используется в имени файла при сохранении) и переключатель
«заменить `+edited+o` в имени файла на `o`» — для итоговых версий.
