## 5 способов включить режим Voice

1. Нажать ссылку **Voice** вверху страницы (рядом с En, Ru и др.).
2. Нажать на иконку 🔉 слева от названия текста.
3. Кликнуть на любое предложение пали или перевода, чтобы оно выделилось —
   появится кнопка **Play** в правом нижнем углу.
4. Навести курсор/нажать перед строкой или после неё — появится ссылка
   **✦**, выбрать «Слушать».
5. Нажать **Alt+R** (**Option+R** на Mac).

## Встроенный плеер

Использует Google Cloud Voices или синтез речи браузера.

- **Управление** — кнопки Play/Pause, переход к предыдущему/следующему
  предложению.
- **Навигация** — поставьте на паузу, кликните на предложение пали, чтобы
  выделить его, нажмите Play, чтобы продолжить с этого места.
- **Настройки** — режим чтения (пали / пали+перевод / перевод /
  перевод+пали) и скорость.
- **Scroll** — вкл/выкл автопрокрутку.
- **Autoplay** — вкл/выкл автовоспроизведение (зависит от политики
  браузера).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+R | Вкл/Выкл режим Voice |
| S | Вкл/Выкл автоскролл |
| Space | Воспроизведение / Пауза |
| ← → или ↑ ↓ | Предыдущий / Следующий сегмент |
| 1 | Режим: пали |
| 2 | Режим: пали + перевод |
| 3 | Режим: перевод |
| 4 | Режим: перевод + пали |
| + / - | Увеличить / уменьшить скорость |
| R | Сбросить скорость до значения по умолчанию |

## Голос пали на вашем устройстве

Отдельного TTS-модуля для пали не существует. Установите один из голосов
**Sanskrit (India)**, **Hindi (India)**, **Nepali** или **Indonesian** —
это ближе всего к произношению пали; если ни один не установлен, в
качестве запасного варианта используется английский.

- **Android** — Настройки → Язык и ввод → Синтез речи → Установка голосовых данных.
- **iOS** — Настройки → Универсальный доступ → Озвучивание содержимого → Голоса.
- **ПК / macOS** — установите системный голос через настройки ОС.

## Google API Key (необязательно)

Включает облачный синтез речи Google Cloud Text-to-Speech — качественные
голоса и щедрые бесплатные лимиты: создайте API-ключ в Google Cloud
Console и включите **Text-to-Speech API**.
