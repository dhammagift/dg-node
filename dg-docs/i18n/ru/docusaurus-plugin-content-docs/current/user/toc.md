# Навигатор TOC

Оглавление всего канона (Сутта Питака + Виная), отдельное от TOC самого
ридера для одной сутты (см. [Ридер](/read)) — здесь можно
просматривать всю коллекцию и переходить прямо в нужную главу.

<AppFrame src="/toc" title="Живой навигатор TOC" height={700} />

## Возможности

- **Ленивое дерево** — книги и главы раскрываются по запросу, а не
  загружаются целиком заранее.
- **Фильтр переводчиков** — панель фильтра сужает дерево до глав, у которых
  есть перевод на выбранный язык(и), с чекбоксами по переводчикам и кнопкой
  «показать ещё» для менее распространённых.
- **Сворачиваемая боковая панель** — состояние открыта/закрыта запоминается
  (`localStorage`).
- **Инлайн-просмотр** — клик по правилу Винаи показывает текст прямо на
  месте, без перехода в полный ридер.
- **Короткие ссылки** — `/toc/<id>` работает как ярлык на нужный раздел.
