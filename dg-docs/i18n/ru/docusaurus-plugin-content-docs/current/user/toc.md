# Навигатор TOC

Оглавление всего канона (Сутта Питака + Виная), отдельное от TOC самого
ридера для одной сутты (см. [Ридер](/read)) — здесь можно
просматривать всю коллекцию и переходить прямо в нужную главу. Открыть
можно и прямо из ридера — **Alt+W**.

<AppFrame src="/toc" title="Живой навигатор TOC" height={700} />

## Возможности

- **Ленивое дерево** — книги и главы раскрываются по запросу, а не
  загружаются целиком заранее.
- **Фильтр переводчиков** — панель справа со строкой поиска «Найти
  переводчика…», отдельная группа чекбоксов на каждый язык (со счётчиком
  текстов у каждого переводчика) и общий чекбокс всей группы. Менее
  распространённые переводчики скрыты за ссылкой «Ещё». Отфильтрованное
  дерево скрывает целиком те книги/главы, где ничего не подошло под
  фильтр, а не просто гасит отдельные строки.
- **Сворачиваемая боковая панель** — состояние открыта/закрыта запоминается
  (`localStorage`), по умолчанию открыта на широком экране и закрыта на
  телефоне.
- **Инлайн-просмотр Патимоккхи** — разделы Патимоккха бхиккху/бхиккхуни
  разворачиваются прямо на странице, с текстом на пали и встроенным
  аудиоплеером на каждый подраздел, без перехода в отдельный ридер:

  <img src={TocPatimokkhaInline} alt="Инлайн-просмотр Патимоккхи прямо в навигаторе TOC" style={{maxWidth: 700, display: 'block', margin: '0 auto 1.5rem'}} />

- **Короткие ссылки** — `/toc/<id>` открывает оглавление сразу на нужном
  разделе (например `/toc/mn`, `/toc/sn25`).

:::tip[Фильтр переводчиков — это сохраняемая настройка]
Однажды снятые галочки останутся снятыми и при следующем визите — это
легко забыть и потом удивляться, почему часть переводов «пропала».
Пока фильтр активен, над деревом появляется ссылка **«Фильтр активен —
сбросить»**.
:::

## Кхуддака Никая показана не полностью

Звёздочка **\*** рядом с «Кхуддака Никая» означает, что показаны не все
книги собрания — по умолчанию только Итивуттака, Удана, Сутта Нипата,
Дхаммапада, Тхерагатха и Тхеригатха. Наведите курсор на звёздочку, чтобы
увидеть список:

<img src={TocKhuddakaTooltip} alt="Подсказка: какие книги Кхуддака Никаи показаны по умолчанию" style={{maxWidth: 420, display: 'block', margin: '0 auto 1.5rem'}} />

Остальные книги (Джатаки и другие) включаются в панели «Быстрые
настройки» → «Где искать» — см. [Поиск](/search-guide) — тот же
переключатель управляет и тем, что видно здесь, в TOC.
