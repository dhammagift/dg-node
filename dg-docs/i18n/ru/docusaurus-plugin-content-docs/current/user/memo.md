# Мемо

Инструмент «Memorize & Meditate» — соберите собственную аудио-сессию из
любого текста: точная нарезка по точке/запятой/строке, настраиваемое число
повторов и длительность пауз, гонги медитации, экспорт в MP3, отдельный
режим интервального таймера и режим визуальных подсказок по первой букве
слова для заучивания. См. также [Голос / TTS](/tts) — более
простой плеер прямо в ридере.
