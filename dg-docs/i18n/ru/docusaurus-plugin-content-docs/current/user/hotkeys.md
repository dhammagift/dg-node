# Горячие клавиши

Все сочетания клавиш сайта в одном месте. Работают на главной, в результатах поиска и в ридере.
Сочетания с **Alt** срабатывают, даже когда курсор стоит в поле поиска; на Mac вместо Alt —
**Option**.

:::tip[Попробуйте прямо здесь]
Щёлкните внутри окна ниже (это настоящая страница ридера) и нажимайте любые сочетания из таблиц.
:::

## Везде

| Сочетание | Что делает |
|---|---|
| **Alt+M** | Открыть / закрыть меню (бургер) |
| **Alt+S** | Быстрые настройки |
| **Alt+P** или **Alt+Y** | Быстрое окно (компас): избранное, история, ключевые сутты |
| **Alt+H** | Помощь |
| **Alt+G** | История поиска |
| **Alt+T** | Светлая / тёмная тема |
| **Alt+−** / **Alt+=** | Мельче / крупнее текст |
| **Ctrl+Shift+1** | Язык сайта: русский / английский |
| **Alt+1** | Вне ридера: смена языка, как переключатель RU/EN в меню |
| **/** | Поставить курсор в поле поиска |
| **Esc** | Закрыть открытое окно, меню или оповещение |
| **Ctrl+Shift+F** или **Alt+Shift+F** | Поиск по странице |
| **Ctrl+1** | Главная / поиск |
| **Ctrl+2** | Читать Сутты и Винаю |
| **Ctrl+3** | Читать главами |

## Чтение

| Сочетание | Что делает |
|---|---|
| **Ctrl+→** / **Ctrl+←** | Следующий / предыдущий текст |
| **Alt+1** … **Alt+7** | Режимы ридера (повторное нажатие клавиши текущего режима меняет язык) |
| **Alt+Пробел** или **Alt+Z** | Показать / скрыть второй язык (пали или перевод) |
| **Alt+C** | Одна или две колонки |
| **Alt+V** | Показать / скрыть варианты чтения |
| **Alt+W** | Оглавление текста |
| **Alt+L** | Письмо пали: латиница → деванагари → тайское |
| **Alt+.** или **Alt+,** | Показать / скрыть пунктуацию в пали |
| **Alt+F** | Добавить в избранное / убрать |
| **Alt+R** | Озвучка: запустить / пауза |

## Результаты поиска

| Сочетание | Что делает |
|---|---|
| **Alt+X** или **Shift+Пробел** | Раскрыть / свернуть все результаты |

## Словарь

| Сочетание | Что делает |
|---|---|
| **Alt+A** | Словарь вкл / выкл |
| **Alt+B** | Режим словаря |
| **Alt+J** | Мультивыбор: искать выделенный текст автоматически |
| **Alt+N** | Открыть словарь в отдельном окне с текущим словом |

## Плеер озвучки

Работают, пока плеер открыт, без Alt/Ctrl:

| Клавиша | Что делает |
|---|---|
| **S** | Автопрокрутка вкл / выкл |
| **1** … **4** | Что читать: пали · пали и перевод · перевод · перевод и пали |
| **−** / **+** | Медленнее / быстрее |
| **R** | Обычная скорость |

:::note
В текстовом поле **Ctrl+←/→** и **/** работают как обычно (переход по словам, ввод косой черты) —
перехватываются только сочетания с Alt.
:::
