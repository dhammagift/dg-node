# Dhamma.Gift Full

Второе приложение, сейчас в разработке: тот же сайт, но полностью
офлайн — все тексты, переводы и словарь хранятся на самом устройстве
(кроме принципиально онлайн-функций вроде голосов Google или внешних
словарей — они и на сайте работают только при подключении к интернету).
Те же ярлыки и «Поделиться, чтобы найти» — тот же принцип, что и в
[Dhamma.Gift online](/dhamma-gift-online), подробнее описано на странице
[«PWA: установка прямо из браузера»](/pwa).

Ссылка на скачивание появится здесь, когда приложение будет готово.
